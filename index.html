0. 게임의 목표 이용자
0.6.1부터 말랑소다는 13세 이상 청소년·성인을 위한 힐링 색 정렬 퍼즐로 소개합니다. 콘텐츠의 전체이용가 등급과 목표 이용자 연령은 서로 다릅니다. 별도 13세 미만 실행 차단은 없으며, 모든 이용자에게 아래의 동일한 보호 설정을 유지합니다. 0.6.2부터 시작 시 연령을 묻지 않고 바로 게임에 진입합니다. 기존 진행과 보호 설정은 유지합니다.

1. 이 기기에 저장하는 정보
게임 진행, 재화, 현재 판, 언어·음악·효과음 설정과 선택적 닉네임, 아바타·스킨, 미션·보상 수령·플레이 통계를 기기에 저장합니다. 닉네임은 프로필 표시용이며 공개 게시하지 않습니다. 실명·생년월일·연령·이메일 입력은 요구하지 않습니다. 이전 버전에서 선택한 연령 구간은 기존 저장에 남을 수 있지만 사용하거나 광고 요청·서버로 보내지 않습니다. 연령이나 동의를 자동으로 기록하지 않습니다. 운영자 게임 서버는 없습니다. Google Play Games 저장 인터페이스와 SDK는 포함되어 있고 외부 서비스 프로젝트 설정은 준비했으나, 실제 계정의 저장·복원 검증 전이므로 이 버전은 클라우드 연결·업로드를 제공하지 않습니다. 게임 시작이나 저장 화면 진입만으로 Google 게임 저장 요청을 하지 않습니다. 실제 연결을 제공할 때 전송 정보와 저장·삭제 방법을 다시 안내합니다.

2. 모든 이용자를 위한 광고 보호
모든 이용자에게 같은 아동 보호 광고 설정을 적용합니다. 광고 ID 권한을 제거하고 퍼스트파티 광고 식별자를 비활성화하며 맞춤형·관심 기반 광고 및 리마케팅을 요청하지 않습니다. 광고 콘텐츠는 G 등급으로 제한합니다. 현재는 Google 공식 테스트 보상 광고만 사용하며 운영 광고와 현금 결제는 비활성입니다. 앱 시작 시 광고 SDK를 초기화하지 않고, 이용자가 보상 광고 버튼을 누르면 보호 설정을 적용해 준비합니다. 이 동작은 맞춤형 광고나 운영 광고에 대한 동의를 의미하지 않습니다.

3. 광고 SDK의 데이터 처리
Google Mobile Ads SDK는 광고 제공·측정·진단·부정 이용 방지를 위해 IP 주소(대략적 위치 추정 가능), 앱/광고 상호작용, 성능·진단 및 SDK가 허용하는 식별자 등을 처리할 수 있습니다. 광고 ID 미사용은 모든 정보가 수집되지 않는다는 뜻이 아닙니다. SDK 데이터는 Google로 전송될 수 있고 Google은 전송 중 TLS 암호화를 안내합니다. 실제 처리에는 아동 보호·비개인화·제한된 데이터 처리 설정이 적용됩니다. 테스트 광고도 무수집이라고 보장하지 않습니다.

4. 보관과 삭제
로컬 진행·설정은 앱 데이터 삭제 시 지워집니다. 앱 제거 또는 데이터 삭제로 진행이 사라질 수 있으며 운영자가 복구할 서버 사본은 없습니다. Google이 처리하는 정보의 보관·삭제는 Google 정책과 제어 기능에 따르며 운영자가 즉시 삭제를 보장할 수 없습니다. Android의 개인정보/광고 설정에서 관련 제어 기능을 확인할 수 있습니다.

5. 문의와 권리 요청
본인 또는 보호자는 위 이메일로 개인정보 문의·삭제 요청을 할 수 있습니다. 문의 시 제공한 이메일과 내용은 답변·요청 처리에 사용하며 불필요한 민감정보는 보내지 마세요. 요청 범위를 확인한 뒤 운영자가 처리 가능한 정보와 Google에 요청해야 하는 부분을 안내합니다.

6. 외부 정책 페이지
외부 페이지를 방문하면 호스팅 제공자가 보안 목적의 IP 접속 기록 등을 처리할 수 있습니다. GitHub Pages 게시 시 GitHub의 개인정보 정책이 적용됩니다. 앱 안의 이 안내는 오프라인에서도 볼 수 있습니다.

0. Intended audience
Starting with version 0.6.1, Soft Soda is presented as a relaxing color-sorting puzzle for teens and adults aged 13 and older. Its all-ages content rating is different from its intended audience. There is no separate under-13 access block. The same protections below apply to everyone. Starting with 0.6.2, the game opens without asking for an age. Existing progress and protections are preserved.

1. Information stored on your device
Progress, coins and tools, the current board, language, music and sound preferences, an optional nickname, avatars and skins, mission/reward claims and play statistics are stored locally. The nickname is for your profile and is not publicly posted. A real name, birth date, age or email is not required. An age band selected in an earlier version may remain in an existing save, but is not used or sent to a server or in ad requests. No age or consent is automatically recorded. There is no operator-run game server. A Google Play Games save interface and SDK are included and external project setup is prepared, but real-account save and restore verification is pending, so this version does not provide cloud connection or uploads. Starting the game or opening the save screen does not request Google game saving. Information sent and save/deletion controls will be explained again before a working connection is offered.

2. Advertising protections for everyone
The same child-protection settings apply to everyone. Advertising ID permissions are removed, publisher first-party advertising ID is disabled, and personalized, interest-based and remarketing ads are not requested. Ad content is limited to G. This version uses only official Google test rewarded ads; live ads and cash purchases are disabled. The ad SDK is not initialized on app startup. Selecting a reward-ad button prepares ads with these protections; it does not constitute consent to personalized or live ads.

3. Advertising SDK data
Google Mobile Ads SDK may process IP addresses (which can indicate approximate location), app/ad interactions, performance and diagnostic information and identifiers permitted by the SDK for ad delivery, measurement, diagnostics and fraud prevention. Disabling advertising ID does not mean no information is collected. SDK data may be sent to Google, which documents TLS encryption in transit. Child treatment, non-personalized and restricted data processing settings are applied. Test ads are not a guarantee of no collection.

4. Retention and deletion
Local progress and preferences are erased when app data is cleared. Uninstalling or clearing data can lose progress; the operator has no server backup to restore it. Data processed by Google follows Google's policies and controls; the operator cannot promise immediate deletion of Google's data. Relevant controls may be available in Android privacy and advertising settings.

5. Questions and requests
You or a parent/guardian may email the contact above with privacy questions or deletion requests. The email and information you provide are used to respond and handle the request; do not send unnecessary sensitive information. We will explain what the operator can handle and what must be requested from Google.

6. External policy pages
Visiting an external page may let its hosting provider process security access logs such as IP addresses. A policy hosted on GitHub Pages is subject to GitHub's privacy practices. This in-app policy can be read offline.
